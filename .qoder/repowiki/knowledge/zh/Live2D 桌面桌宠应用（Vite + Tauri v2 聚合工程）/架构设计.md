根目录作为单一 npm workspace 聚合三个子模块：frontend_app（Pixi.js 渲染与交互）、tauri_backend（窗口漫游、音频捕获、托盘等原生能力）与 assets_and_scripts（Live2D 模型、CDP 诊断脚本与图标生成）。package.json 通过 scripts 暴露 dev/build/preview/tauri 命令，由 vite.config.ts 将开发服务器固定监听 127.0.0.1:1420，并通过 TAURI_ENV_* 环境变量区分开发与发布目标；tsconfig.json 以 ESNext + strict 模式编译 frontend_app/src 下的 TypeScript，index.html 作为 Tauri 窗口加载的 HTML 入口并引入 /src/main.ts 启动 Pixi 舞台。前后端通过 @tauri-apps/api 在运行时进行 IPC 通信，assets_and_scripts 提供三者共享的模型与构建期资源，共同构成完整的桌面桌宠产品。
