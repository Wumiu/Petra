- 所有与 Rust 后端的交互统一通过 `invoke(...)` 调用，并以 try/catch 或 `.catch(() => {})` 静默忽略失败，保证前端健壮性。
- 窗口坐标在引擎内部一律使用逻辑像素（CSS 像素），仅在 IPC 边界处乘以 `scaleFactor` 转换为物理像素后再传回 Rust。
- 渲染器通过 `PetView` 接口解耦，`main.ts` 根据运行时条件动态选择具体实现，新增模型类型只需实现该接口并在 `createView()` 中注册。
- 设置项集中由 `utils/settings.ts` 的 `loadSettings`/`saveSettings` 读写 localStorage，并通过模块级 `currentFactor` 缓存活动因子，避免每帧重复解析。
- UI 面板（模型设置、小助手设置）采用统一的 `render(host)` 函数模式：清空 host.innerHTML 后按需重建 DOM，并通过 CSS class `hidden` 控制显隐。
- 长耗时或可选功能（如 pixi-live2d-display）使用 `await import(...)` 动态加载，避免阻塞主链路与增加初始包体。
