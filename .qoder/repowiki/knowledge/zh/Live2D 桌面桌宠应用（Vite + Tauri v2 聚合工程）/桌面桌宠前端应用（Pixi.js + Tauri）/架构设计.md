以 `src/main.ts` 为唯一入口，启动 PIXI.Application 并组装各子系统：
- 渲染抽象层：`live2d/PetDriver.ts` 定义 `PetDriver`（输入数据）与 `PetView`（渲染接口），由 `PlaceholderRenderer`、`Live2DController`、`psd/Rigged2DView` 三种实现分别对应占位角色、标准 Live2D 与 PSD 模型；`createView()` 按优先级从已导入 PSD → manifest 打包 PSD → 动态 import 的 Live2D → 占位符回退。
- 行为引擎：`autonomous/BehaviorEngine.ts` 维护窗口逻辑坐标下的位置、目标点、逗猫棒状态机（idle/sneak/chase/pounce/circle/bored）、待机模式（边缘倒挂）与边界反弹，通过 `invoke("set_pet_target*" | "clear_pet_target")` 将移动指令下发给 Rust mover 线程，自身仅做决策与速度计算。
- 音频链路：`audio/AudioAnalyzer.ts` 订阅 Tauri 事件 `audio:pcm`，用环形缓冲 + Web Audio AnalyserNode 做 FFT，输出 bass/mid/treble/beat 供驱动层使用。
- 交互与 UI：`ui/ContextMenu.ts`、`ui/Toast.ts` 提供自定义右键菜单与提示；`features/trash/TrashHandler.ts` 处理 PSD 文件拖放；`assistant/AssistantPanel.ts` 与 `AssistantClient.ts` 管理小助手对话框生命周期与模型列表获取；`bridges/astrobot.ts` 暴露外部事件钩子。
- 配置与工具：`utils/settings.ts` 集中持久化 Settings（含 AssistantSettings），`utils/math.ts` 提供 clamp 等基础函数。
依赖方向单向收敛于 `main.ts`：各子模块只导出类/函数，不反向引用主循环；IPC 调用集中在 BehaviorEngine 与 main 中，保持前端纯 JS 侧无副作用。
