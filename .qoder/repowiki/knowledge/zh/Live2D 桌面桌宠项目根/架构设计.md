根目录作为单一 npm workspace 聚合三个子模块：frontend_app（基于 Pixi.js/Tauri 的前端）、tauri_backend（Tauri v2 原生能力）与 assets_and_scripts（模型与构建脚本）。package.json 通过 scripts 暴露 dev/build/preview/tauri 命令，由 vite.config.ts 将开发服务器固定监听 127.0.0.1:1420，并通过 TAURI_ENV_* 环境变量区分开发与发布构建目标；tsconfig.json 以 ESNext + strict 模式编译 src 下的 TypeScript，index.html 作为 Tauri 窗口加载的 HTML 入口，引入 /src/main.ts 启动 Pixi 舞台。前后端通过 @tauri-apps/api 在运行时通信，assets_and_scripts 提供 Live2D 模型与图标生成等共享资源，三者共同构成完整的桌面桌宠产品。
