- 所有对前端的原生能力均通过 `#[tauri::command]` 函数暴露，并在 `generate_handler![]` 中集中注册。
- 跨线程共享状态统一封装为自定义 struct（如 AudioState、PetMotion、DragState），通过 Tauri `.manage()` 注入并由 `State<'_, T>` 在命令中读取。
- 高频 UI 更新（窗口移动、拖动跟随、点击穿透）采用固定间隔后台线程（8ms/16ms）轮询状态并直接调用 Win32 SetWindowPos，避免每帧 IPC 延迟。
- Win32 调用集中在 screen.rs / trash.rs / audio.rs 三个子模块，lib.rs 仅编排命令与线程生命周期，保持职责分离。
- 日志统一经 `log_line` 写入 stdout 与 app_data_dir/logs/pet.log，panic 钩子也接入同一通道，便于打包后定位问题。
- 对外部输入（路径、文件名）进行白名单或清洗处理后再落盘或执行（如 PSD 文件名 sanitize、system path 过滤、只接受 .psd 后缀）。
