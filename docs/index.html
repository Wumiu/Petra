FEATURES

它到底能做什么

角色、行为、AI、桌面能力——四块拼起来，就是一只真正住在你电脑里的小家伙。

自定义角色

  • 拖入分层 PSD 自动生成 2.5D 角色：自动眨眼、发丝物理、表情变形，全本地离线，不需要 Cubism Editor
  • 同时支持标准 Live2D 模型（model3.json），现成模型可直接导入
  • 视线追踪：眼睛带死区和平滑，会自然看向你的鼠标
  • 内置 DeepSeek 大肥鱼、Elaina 等多个角色，右键一键切换

桌宠行为

  • 桌面漫游：在当前屏幕工作区内随机闲逛，活跃度低 / 中 / 高三档可调
  • 鼠标靠近自动躲避，逗猫棒模式反过来追着鼠标跑
  • 点头、摇头、挥手、打哈欠、伸懒腰等 14 个动作，按节奏自动播放
  • 待机时贴屏幕边缘倒挂，拖一下就醒；拖拽时软乎乎晃、带惯性

AI 小助手 · 可接入你自己的 API

  • 内置 DeepSeek，开箱即可流式对话，回复逐字蹦出来
  • 说「打开网易云」就能按应用名帮你启动软件，不靠 AI 猜路径
  • Shell 能力执行前弹确认，危险命令一律拦截，15 秒自动超时
  • 长期记忆你的偏好，每 20 分钟识别前台窗口主动打招呼，人格可自定义
什么是 API？接入要花钱吗？

API 就像软件和 AI 服务器之间的一条电话线。你填入自己的 API Key 后，对话由 AI 服务商（如 DeepSeek）直接响应，用量费用由服务商按你的实际消耗收取——Petra 不经手、不分成、不额外收费。所有带 AI 的软件都是这个模式，我们不靠这个赚你的钱；不填 Key 也能当普通桌宠玩。

桌面与音乐

  • WASAPI 回环捕获系统音频，驱动身体律动、嘴型、眉毛和发丝
  • BPM 节拍检测，跟着音乐节奏摇摆、打拍眨眼
  • 托盘图标 + Alt+P 随时隐藏唤出，支持开机自启
  • 启动自动检查更新；把文件拖到它身上，直接送进回收站
